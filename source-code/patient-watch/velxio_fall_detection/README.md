# Fall Detection ESP32-CAM — Velxio/Wokwi import

The archive must keep `diagram.json` at its root. In Velxio choose **Open Project** and select the `.zip` file itself (do not select the containing folder).

The circuit uses the Velxio ESP32-CAM pin names: GPIO13/14 for MPU6050 I2C, GPIO12 for the emergency button, GPIO2 through a 220-ohm resistor to the green LED, and GPIO15 for the buzzer. All grounds are common.
